# How to Install Sallay Beta (For Testers)

Thank you for testing Sallay! Here's how to install the app on your Android device.

## Installation Steps

### Method 1: Direct Install (If you have the APK file)

1. **Enable Unknown Sources**:
   - Go to your phone's **Settings**
   - Navigate to **Security** (or **Apps & notifications** → **Special app access** on some devices)
   - Enable **Install unknown apps** or **Unknown sources**
   - Select the app you'll use to install the APK (e.g., Chrome, Files, WhatsApp)

2. **Install the APK**:
   - Download the `app-release.apk` file I sent you
   - Open the APK file from your Downloads folder or notification
   - Tap **Install**
   - Wait for installation to complete
   - Tap **Open** to launch Sallay

### Method 2: Install via ADB (For developers)

If you have Android Debug Bridge (ADB) set up:
```bash
adb install app-release.apk
```

## First Launch

When you open Sallay for the first time:

1. **Grant Location Permission**: Sallay needs your location to calculate accurate prayer times
2. **Grant Notification Permission**: Enable notifications to get prayer time alerts
3. **Complete Onboarding**: Follow the simple setup screens
4. **Set Your Location**: Choose to use GPS or manually enter your city
